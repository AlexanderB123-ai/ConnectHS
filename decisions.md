# Architecture Decision Log

Append-only log of significant decisions. One line per entry. Format: `YYYY-MM-DD — what changed — why`.

## Initial decisions (from PRD)

- 2026-01-15 — Stack: SwiftUI + Swift 6 + Supabase + WidgetKit — native required for widget perf and dual-camera; Supabase = Postgres + RLS + Storage + Realtime + Edge Functions in one platform
- 2026-01-15 — Min iOS: 17.0 — covers ~95% of devices, gives modern @Observable, AVCaptureMultiCamSession, Interactive Widgets
- 2026-01-15 — Architecture: MVVM with @Observable view models — modern, lightweight, plays well with SwiftUI
- 2026-01-15 — Auth: phone OTP + Sign in with Apple only — no email/password (App Store guideline 5.1.1(v))
- 2026-01-15 — Closed graph only — no public feed, no discovery, no follower counts (anti-brand for v1)
- 2026-01-15 — Permanent archive — anti-BeReal differentiator; posts NEVER expire
- 2026-01-15 — Memory Engine — primary retention mechanic (vs streaks, which create anxiety)
- 2026-01-15 — One post per user per group per day — DB unique index enforces; deliberate scarcity
- 2026-01-15 — Apple Developer Program enrollment — deferred to Alexander's 18th birthday (June 16, 2026); use free Personal Team for dev
- 2026-01-15 — Public launch target — June-August 2026 (US graduation window); miss it = lose 12 months
